Run these commands to setup the workspace 
```
git clone https://github.com/GaneshIyer1008/Robot_Learning_Cloth_Folding.git
cd Robot_Learning_Cloth_Folding
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
```
